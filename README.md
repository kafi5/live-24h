# LoopLive (Android)

আগে বানানো ভিডিও YouTube-এ লাইভ পাঠানোর অ্যাপ। ভিডিও বাছুন, YouTube-এর RTMP/RTMPS লিংক বসান, Shorts বা Long বেছে Start Live চাপুন। ভিডিও লুপে চলে, স্ক্রিন বন্ধ থাকলেও।

## ২৪ ঘণ্টা ব্যাকগ্রাউন্ডে চলার জন্য অ্যাপে যা আছে

- Foreground service (mediaPlayback ধরন): নোটিফিকেশনসহ চলে, Android সহজে বন্ধ করে না।
- CPU wake lock ও Wi-Fi lock: স্ক্রিন বন্ধ হলেও ফোন ঘুমায় না, Wi-Fi চালু থাকে।
- অটো রিকানেক্ট: লিংক কেটে গেলে ৩, ৬, ৯ সেকেন্ড করে বাড়িয়ে (সর্বোচ্চ ১ মিনিট) আবার যুক্ত হয়। ইন্টারনেট ফিরলে সঙ্গে সঙ্গে চেষ্টা করে।
- স্টল ডিটেকশন: ৩০ সেকেন্ড কোনো ডেটা না গেলে স্ট্রিম নিজে থেকে নতুন করে শুরু হয়।
- প্রসেস মারা গেলে সার্ভিস নিজে থেকে আবার চালু হয় (যতক্ষণ আপনি Stop না চাপেন)।
- ব্যাটারি "Unrestricted" করার অনুরোধ অ্যাপ নিজেই দেখায়।
- ভিডিও অ্যাপের নিজস্ব স্টোরেজে কপি হয়, তাই গ্যালারি থেকে ফাইল মুছলেও স্ট্রিম চলে।

## APK বানানোর উপায়

### ১. GitHub Actions দিয়ে (কম্পিউটারে কিছু ইনস্টল লাগে না)

1. GitHub-এ একটি নতুন repository খুলুন (Private রাখতে পারেন)।
2. এই ফোল্ডারের সব ফাইল আপলোড করুন। `.github` ফোল্ডার আর `gradlew` ফাইল যেন বাদ না যায়।
3. repository-র **Actions** ট্যাবে যান, **Build APK** বেছে **Run workflow** চাপুন।
4. কয়েক মিনিট পর কাজ শেষ হলে নিচে **Artifacts**-এ `LoopLive-apk` পাবেন। সেটা নামিয়ে zip খুলুন, ভেতরে `LoopLive.apk`।
5. ফোনে APK খুলে ইনস্টল করুন (Install unknown apps অনুমতি লাগবে)।

প্রথম বিল্ড লাল (ব্যর্থ) হলে সেই run খুলে error লাইনটা কপি করে আমাকে পাঠান। এই কোড এখনো কোনো মেশিনে কম্পাইল করে দেখা হয়নি, তাই ছোটখাটো ভুল থাকতে পারে।

### ২. Android Studio দিয়ে

ফোল্ডারটা Android Studio-তে Open করুন, Gradle sync শেষ হলে **Build > Build APK(s)**।

## ফোনে এই সেটিংগুলো করে নিন

ফোনের কোম্পানি ব্যাকগ্রাউন্ড অ্যাপ জোর করে বন্ধ করে দেয়। ২৪ ঘণ্টা চালাতে চাইলে:

- **সব ফোন:** Settings > Apps > LoopLive > Battery > **Unrestricted** (বা No restrictions)।
- **Xiaomi / Redmi / Poco:** Autostart চালু করুন। Battery saver এ LoopLive-কে **No restrictions** দিন। Recent apps খুলে LoopLive কার্ড নিচে টেনে **Lock** করুন।
- **Tecno / Infinix:** Phone Master বা Settings থেকে LoopLive-কে Auto-start ও Background run এ অনুমতি দিন, আর Battery optimization থেকে বাদ দিন।
- **Samsung:** Settings > Battery > Background usage limits > **Never sleeping apps** এ LoopLive যোগ করুন।
- ফোন চার্জারে লাগিয়ে রাখুন এবং ঠান্ডা, খোলা জায়গায় রাখুন। এনকোডিং করতে ফোন গরম হয়।
- Wi-Fi ব্যবহার করুন। মোবাইল ডেটায় ২৪ ঘণ্টায় অনেক GB খরচ হয় (নিচের টেবিল দেখুন)।

## YouTube থেকে লিংক নেওয়া

YouTube Studio > Create > Go live > Stream। সেখানে **Stream URL** আর **Stream key** আলাদা থাকে। অ্যাপের লিংক ঘরে দুটো জুড়ে এভাবে বসান:

```
rtmps://a.rtmps.youtube.com:443/live2/আপনার-স্ট্রিম-কী
```

স্ট্রিম কী কাউকে দেবেন না।

## যা জেনে রাখা দরকার

- **Shorts / Long বোতাম:** স্ট্রিমের আকার ভিডিওর নিজের আকারের (পিক্সেল) সমান থাকে। বোতামটা শুধু দেখে, ভিডিও আপনার বাছা ফরম্যাটের সাথে মিলছে কিনা, না মিললে সতর্ক করে। আসলে Shorts হিসেবে দেখাবে কিনা সেটা YouTube ঠিক করে।
- **ভিডিও:** H.264 MP4 সবচেয়ে নিরাপদ। ঘোরানো (rotation flag) ভিডিও কাত হয়ে যেতে পারে, তখন আবার এক্সপোর্ট করে নিন।
- **YouTube-এর নীতি:** একই কনটেন্ট বারবার চালালে পুনরাবৃত্ত বা পুনর্ব্যবহৃত কনটেন্টের নীতিতে আয় বন্ধ হতে পারে। শুধু নিজের বানানো বা অনুমতি নেওয়া কনটেন্ট দিন।
- **এখনো যা বাকি:** আসল ফোনে ২৪ ঘণ্টার টানা পরীক্ষা করা হয়নি। প্রথমে ১-২ ঘণ্টা চালিয়ে দেখুন, তারপর পুরো দিন।

## কোডের গঠন

| ফাইল | কাজ |
|---|---|
| `MainActivity.kt` | স্ক্রিন, ভিডিও বাছা ও কপি, লিংক যাচাই, Start/Stop |
| `StreamService.kt` | ব্যাকগ্রাউন্ড সার্ভিস, লুপ স্ট্রিম, রিকানেক্ট, লক, নোটিফিকেশন |
| `Prefs.kt` | সেটিং ও বাছা ভিডিওর তথ্য মনে রাখা |
| `StreamStore.kt` | লাইভ অবস্থা (সার্ভিস থেকে স্ক্রিনে) |
